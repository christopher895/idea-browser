# Design
An editorial idea library: warm ivory background, dark ink, restrained forest green, serif headlines, sans-serif controls. Dense readable rows rather than a marketing landing page. Primary path is search → idea → full report → save and annotate. Responsive two-column reports collapse to one column. No stock imagery or invented numeric opportunity scores. Researched reports lead with the verdict and next step, and end with an evidence log showing each source's type, dates, supported claim, and limits. Evidence strength uses the named levels from the research method, never a number.

The email-digest surface inherits the same colors, typography, and page width. It presents an explicit setup state, followed by a readable preview containing evidence status, first test, risk, and a report link. It has no signup control until a real subscription backend exists. The setup block and definition lists stack on mobile.
