# Research-first roadmap

## 1. Produce a small useful collection

- Research a mix of solo-buildable software/AI ideas, businesses with existing spending, and opportunities aligned with the builder's experience.
- Use `research/IDEA_TEMPLATE.md` for each candidate.
- Link the actual evidence and include counterarguments.
- Separate starter concepts from researched reports.

Done when a reader can inspect why each selected opportunity deserves customer investigation without trusting an unexplained score.

## 2. Build a reusable evidence store

- Store source URL, date, source type, segment, observation, and supported claims.
- Deduplicate underlying signals.
- Track verification and freshness.
- Keep demand strength, feasibility, and founder fit separate.

Done when every material claim in a report can be traced to evidence or a labeled assumption.

## 3. Add bounded discovery automation

- Select accessible sources based on actual research value.
- Introduce source adapters, caching, rate limits, and an explicit cost ceiling.
- Use AI to group and summarize evidence with human review before publication.
- Flag unsupported claims and failed source fetches.

Done when repeated runs produce inspectable new candidates without silently inventing facts or exceeding the budget.

## 4. Connect the collection to the browser

- Replace or clearly segregate the initial concept briefs.
- Filter by evidence level, customer, business model, implementation burden, and personal fit.
- Expose source dates, verdict rationale, and next validation step.
- Add backup import and decide whether cross-device storage is actually needed.

Done when browsing helps the user choose an experiment, not merely collect more ideas.

## 5. Learn from outcomes

- Record interviews, offers, pilot commitments, usage, renewal, and costs.
- Compare original predictions with outcomes.
- Revise the research method when evidence shows its weaknesses.

Success is useful selection and real customer progress. Idea count, attractive reports, and high scores are not success metrics by themselves.
